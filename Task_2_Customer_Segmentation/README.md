# Task 2: Customer Segmentation using K-Means Clustering 🎯

This repository contains the full documentation, source code, and analytical assets for **Task 2 (Customer Segmentation)** as part of the Data Analytics Internship at **Intern Alpha**.

---

## 📌 Project Objective
The goal of this project is to perform market basket and demographic analysis using unsupervised machine learning. By applying the **K-Means Clustering** algorithm, the project segments a retail company's customer base into distinct groups based on their spending habits and income levels. This allows businesses to craft highly targeted marketing strategies for different consumer profiles.
